# Spalla

Web app per il recupero della spalla sinistra: 6 esercizi isometrici × 3 giri e pendolo finale.
Timer a liquido, figure animate, promemoria di postura, schermo sempre acceso.

**Installazione su iPhone:** apri il sito con Safari → Condividi → Aggiungi alla schermata Home.

Funziona offline dopo la prima apertura (service worker).
Il video invisibile che tiene acceso lo schermo viene da [NoSleep.js](https://github.com/richtr/NoSleep.js) (licenza MIT).
